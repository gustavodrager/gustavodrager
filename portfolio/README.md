# Projetos e tecnologias — Gustavo Drager

Resumo técnico dos projetos, com base no recorte de 2026-09-08. A API e a interface web da plataforma QuebraNunca aparecem juntas. Os repositórios de demonstração foram retirados do GitHub em 2026-09-11; esta página mantém apenas a descrição dos trabalhos, sem disponibilizar código.

| Projeto | Tecnologias no recorte | Escopo técnico |
|---|---|---|
| LavaMais CRM | .NET 10 · Next.js · PostgreSQL | Monolito modular, BFF, identidade local e WhatsApp assistido |
| QuebraNunca — plataforma | .NET 10 · React · PostgreSQL | API e web: grupos, partidas, rankings, arenas e permissões |
| QuebraNunca CRM | .NET 10 · React/Vite · PostgreSQL | Snapshot histórico: tenants, importações, finanças e integrações |
| Parsero | Next.js · Prisma · PostgreSQL · .NET 10 | Conversas, adapters de mensagens, fila e fundação .NET em evolução |
| Portal AD7 | React · TypeScript · Drizzle · D1/R2 | Portal associativo, modelo relacional e importação de contatos |
| Liga Praiagrandense | React · .NET 10 · PostgreSQL | Ranking, prévia de importação, revisão e auditoria |
| Sam Motos | React · .NET 10 · Identity · EF Core | Base de gestão de oficina em desenvolvimento |
| Central de Identidade | .NET 10 · Identity · OpenIddict · PostgreSQL | Em desenvolvimento: OAuth/OIDC, PKCE, tenants e outbox |
| Central de Notificações | .NET 10 · PostgreSQL | Em desenvolvimento: fila, idempotência, retry e adapters |
| QN Reserva Sync | .NET 10 · PostgreSQL | Catálogo GET-only, checkpoints e propostas de revisão humana |
| WhatsMiau Task Inbox | TypeScript · AI SDK · Zod | Webhook, classificação, deduplicação e adapters de tarefas |
| AI Engineering Study | Python · Markdown · JavaScript | Gerador estático e trilha de estudo; conteúdo não equivale a experiência implementada |
| QuebraNunca API — legado | .NET 8 · EF Core · MassTransit | Implementação parcial: CQRS, read/write contexts e eventos |
| QuebraNunca Web — legado | React · Vite · JavaScript | Protótipo inicial de autenticação |
| QuebraNunca Mobile — legado | React Native · Expo · TypeScript | Protótipo inicial de navegação e autenticação |
| Redirecionamento de domínio | Configuração declarativa | Exemplo mínimo de redirecionamento com preservação de caminho |

Projetos incompletos e versões legadas são identificados como tais. As descrições refletem o recorte técnico registrado, não uma distribuição integrada pronta para uso. Repositórios operacionais, históricos e dados pessoais ou comerciais permanecem privados.
