# Portfólio técnico — Gustavo Drager

17 projetos locais representados em 16 repositórios públicos. A API e a interface web da plataforma QuebraNunca estão reunidas no mesmo showcase. Coleta: 2026-09-08.

Cada repositório apresenta código, dependências, um roteiro de arquitetura e o estágio do recorte. Os fontes em `codigo/` são cópias sanitizadas para leitura técnica; os exemplos independentes anteriores continuam em `exemplos/`. Projetos incompletos e versões legadas são identificados como tais.
